# 📚 BookNest – Personal Book Collection & Reading Management System

A simple R Shiny application to track and analyze your personal reading habits WITHOUT ML/DL.

### 🔥 Features
- **1. Book Data:** View raw dataset (Book_ID, Title, Author, Genre, Rating, Pages_Read)
- **2. Extract:** Extract any column using c() & indexing
- **3. Sequence:** Generate Book ID sequence using seq()
- **4. Combine:** Combine authors/genres using c() & unique()
- **5. Monthly Reading:** Bar chart for monthly books/pages read
- **6. Average Rating:** Calculate mean() rating of favorite books
- **7. Summary:** Total Books, Total Pages, Avg Rating, Concepts Used

### 🛠️ Tech Stack
- R Programming
- R Shiny (127.0.0.1:3064)
- Concepts: c(), seq(), unique(), mean(), barplot

### 🚀 How to Run
install.packages(c("shiny","dplyr"))
runApp("app.R")
